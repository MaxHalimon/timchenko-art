# Montserrat — локальні файли шрифту

✅ Файли вже на місці, нічого робити не треба — цей файл лишився як
довідка про походження та ліцензію.

## Джерело

Офіційний пакет із Google Fonts (`fonts.google.com/specimen/Montserrat`,
дизайнер Julieta Ulanovsky, ліцензія SIL Open Font License — `OFL.txt`
поруч, теж з оригінального архіву). З пакету взято 4 статичні
насиченості (`static/Montserrat-*.ttf`) і сконвертовано в `.woff2`.

| Файл | Насиченість | Використання |
|---|---|---|
| `Montserrat-Regular.woff2` | 400 | основний текст |
| `Montserrat-Medium.woff2` | 500 | заголовки (`h1`–`h4`), акценти |
| `Montserrat-SemiBold.woff2` | 600 | кнопки, підкреслені акценти |
| `Montserrat-Bold.woff2` | 700 | де потрібна максимальна вага |

`app/[locale]/globals.css` підключає їх через `@font-face` — більше
нічого чіпати не треба, якщо колись знадобиться замінити файли (інша
насиченість, варіативний шрифт тощо) — просто покладіть нові файли сюди
з тими самими іменами.
